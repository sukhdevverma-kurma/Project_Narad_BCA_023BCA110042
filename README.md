## 📌 Project Overview
Project Narad is a lightweight, decentralized network interception and real-time distress communication routing system. It is engineered to function autonomously during emergency infrastructure failures or rescue management operations, intercepting dynamic network requests and presenting an instantaneous localized communication layer.

## 🛠️ Core Technology Stack
* **Language:** Python 3.x
* **Core Networking Engine:** Raw UDP Sockets (Custom DNS Layer)
* **Backend Application Server:** Flask Ecosystem
* **Real-time Pipeline:** Flask-SocketIO (Asynchronous Bi-directional WebSocket Routing)
* **Frontend Architecture:** Integrated HTML5 / System Responsive Templates

## 📁 Repository Structure
* `app.py` - The primary backend web application server handling the user interface and WebSocket message pipelines.
* `dns_server.py` - The core DNS interception subsystem managing network capturing and redirection layers.
* `/templates` - Web user interface directory managing responsive layouts for connected client nodes.
